# POS MiniMarket Releases

Repositorio público usado únicamente para distribuir actualizaciones de la aplicación POS MiniMarket.

Este repositorio no contiene el código fuente del sistema.
Solo almacena los archivos necesarios para que la aplicación pueda detectar, descargar e instalar nuevas versiones mediante el actualizador automático.

## Archivos publicados en cada release

Cada versión puede incluir archivos como:

- POS MiniMarket Setup x.x.x.exe
- latest.yml
- POS MiniMarket Setup x.x.x.exe.blockmap

## Instalación y actualizaciones

Los usuarios deben instalar la aplicación usando el instalador publicado en la sección Releases.

La aplicación verificará automáticamente si hay nuevas versiones disponibles y mostrará un aviso dentro del sistema cuando exista una actualización.

## Código fuente

El código fuente de este proyecto es privado.
